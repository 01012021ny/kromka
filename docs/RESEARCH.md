# Исследование (30.10.2026): чего не хватает дизайнерам и что важно для авангардного кроя

## Боли существующих инструментов
- **Цена и доступ.** CLO ≈ $50/мес, Style3D ≈ $40, Marvelous ≈ $39; Browzwear не продаёт индивидуальные лицензии;
  Optitex/Lectra/Gerber — только корпоративно; Seamly2D/Valentina бесплатны, но без 3D.
  ([сравнение](https://www.delogue.com/blog/clo3d-vs-browzwear-vs-optitex-vs-style3d-3d-fashion-software), [CLO plans](https://www.clo3d.com/plans))
- **2D→3D вместо наколки.** Основной сценарий — нарисовать лекала и «сшить» на аватаре; правка лекал в 3D ограничена
  (у Browzwear правки только в 2D; у CLO есть Flatten по линиям на аватаре). ([CLO Flatten](https://support.clo3d.com/hc/en-us/articles/115012223847-Flatten))
- **Физика.** Eurographics 2024: даже свежие методы плохо воспроизводят растяжение по драп-тесту (R² ≈ 0,61),
  закручивание кромки трикотажа и асимметрию косой. ([статья](https://diglib7.eg.org/bitstream/handle/10.1111/cgf15027/v43i2_20_15027.pdf))
- **Кожа** в 3D заметно хуже тканей по сходству с реальным изделием (≈0,5 против 0,6–0,7). ([IULTCS](https://iultcs.org/wp-content/uploads/2021/09/An-investigation-on-usability-of-3D-visualization-and-simulation-program....pdf))
- **Слои** чинят вручную (заморозка, Layer 0/1). ([форум CLO](https://support.clo3d.com/hc/en-us/community/posts/360018549074-Layers-over-padding))
- **Постобработка.** Стирки визуализируются только для денима; связь «garment dye → усадка → лекала» не делает никто,
  хотя у трикотажа без контроля усадки она доходила до 22 % по длине. ([Cotton Inc](https://www.cottoninc.com/wp-content/uploads/2017/12/TRI-3003-Garment-Dyeing-of-Cotton-Apparel.pdf))
- **Нестинг** считает отходы постфактум на готовых деталях. ([CLO Nest](https://support.clo3d.com/hc/en-us/articles/115000565568-Nest-Patterns?page=1))

## Zero-waste
- При обычном раскрое теряется ≈10–15 % ткани. ([Rissanen](https://opus.lib.uts.edu.au/bitstream/10453/23384/11/01front.pdf), [PLATE 2025](https://journals.aau.dk/index.php/plate2025/article/download/10350/8430/34511))
- Rissanen: конструирование — часть дизайна, а не этап после него. McQuillan: пальто из 150 см ткани против 250 см
  у обычного аналога; «zero waste matrix»; проблема — перенос решения на другую ширину. ([McQuillan](https://hollymcquillan.com/wp-content/uploads/2018/02/rffp_a_1400320.pdf))
- Julian Roberts — subtraction cutting (работа от «пустоты» тела); A-POC (Miyake/Fujiwara) — изделия вплетены в трубу;
  Yeohlee Teng — геометрия на всю ширину с кромкой.
- Обрезки — ресурс: либо довести лекало до нуля отходов, либо стандартизировать раскладку, чтобы остатки были одинаковыми.

## Приёмы ориентирных брендов
- **Rick Owens**: драпировка и косой крой, удлинённые рукава, асимметричные застёжки, заниженная мотня, сырые края,
  вощёные и состаренные материалы. ([wiki](https://en.wikipedia.org/wiki/Rick_Owens))
- **Carol Christian Poell**: object dyeing, эксперименты с кожей, брюки из одной детали со спиральным швом.
- **Boris Bidjan Saberi**: конская кожа растительного дубления, ручная доработка, моделирование на теле.
- **Julius**: многослойность, «монашеская» драпировка при точной посадке, чёрная индустриальная эстетика.
- **L.G.B. / if six was nine**: ручная работа, асимметрия как деформация симметричной базы, дистресс, кожа.
- **Number (N)ine**: дистресс, сырые края, перешив секонд-хенда. **Ann Demeulemeester**: асимметричные брюки,
  монохром. **Balmain**: байкерские рибовые вставки на коленях.
- Сквозное: асимметрия, косая, drop crotch, длинные рукава, сырые края, garment/object dye, обработанная кожа, слои.

## Плотности (ориентиры)
Кулирка 120–220 г/м²; рибана 210–280; футер 200–350; флис 250–400; поплин 110–150; марля 110–140; лён 150–250;
деним 12 oz ≈ 407 г/м² (1 oz/yd² ≈ 33,9 г/м²); мельтон 300–650; шёлк 1 momme ≈ 4,3 г/м² (шифон ≈ 26, шармёз ≈ 82);
кожа ягнёнка 0,6–1,0 мм, КРС 0,8–1,4+, конская 1,2–1,4+.
