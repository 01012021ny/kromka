# КРОМКА — студия кроя

Закрытый проект — все права защищены (см. [LICENSE](LICENSE)). Публичного деплоя нет; рабочие сборки — приватный предпросмотр.

> Кромка — край ткани, который не осыпается и не уходит в отходы. Zero-waste крой идёт «до кромки».

3D-конструктор одежды: параметрический манекен, лекала от мерок, физика тканей (XPBD), разрезы на цветовые блоки,
накладки, принты, фурнитура, обувь и аксессуары, градация размеров и раскладка без отходов.
Сборка — один файл `dist/index.html`, открывается в браузере без сервера.

## Команды

```bash
npm install
npm run build     # → dist/index.html (физика собирается отдельным бандлом и запускается в Web Worker)
npm test          # регрессионные тесты физики, лекал, градации, раскладки и экспорта (~20 с)
npm run typecheck # проверка типов TypeScript поверх JS
npm run e2e       # сборка + e2e-сценарии в браузере (Playwright)
```

Откройте `dist/index.html#local`, чтобы запустить физику в основном потоке (удобно для отладки и e2e-тестов).

## Устройство

| Модуль | Что делает |
|---|---|
| `src/body.js` | манекен: мерки из пола/роста/веса/% жира, лофт-сетка, аналитический SDF + воксельная сетка SDF для коллизий |
| `src/patterns.js` | модель детали (точки, углы, мета сторон), базовые конструкции (плечевые, брюки и джинсы — прямые, bootcut, клёш, skinny, stacked, широкие; юбка, снуд), разрез, деление сторон, швы |
| `src/sim.js` | XPBD-решатель: растяжение с анизотропией нити, изгиб, шитьё, ограничение деформации, обручи горловин/поясов, ремни, кулоновское трение, ткань–ткань (слои + самопересечения) |
| `src/simworker.js`, `src/simproxy.js` | физика в Web Worker и фасад с тем же API на основном потоке |
| `src/materials.js` | волокна, переплетения, 49 основ тканей, вывод физики из состава/плотности, процедурные текстуры |
| `src/grading.js` | градация: поле смещений между размерами базовой конструкции переносит ручные правки на все размеры |
| `src/layout.js` | растровая раскладка (bottom-left, несколько порядков), остатки и идеи их использования |
| `src/export.js` | PDF А4 1:1 плитками, DXF (AAMA-блоки), PLT (HPGL), ZIP, SVG-веер размеров |
| `src/editor2d.js`, `src/view3d.js`, `src/main.js` | 2D-редактор лекал, 3D-вид, оркестрация |
| `src/ui.js`, `src/ui/` | интерфейс: шапка и клавиши, панели вкладок, инспектор, тулбар 2D, вид раскладки, меню «Файл» и экспорт для производства |
| `tests/suite.js` | регрессии: изделия держатся на теле и не проходят сквозь него, рукав обхватывает руку, разрез сохраняет площадь, градация не разводит швы, раскладка не зеркалит детали, экспорт валиден |

## e2e

`e2e/*.spec.js` — сценарии Playwright на собранном `dist/index.html`: физика в воркере и в основном потоке (садится, не сползает, без NaN), 2D-редактор (перетаскивание точки, разрез от руки с сохранением площади, отмена, экспорт из меню), все вкладки и инспекторы, производство (тираж в раскладке, PDF А4, ZIP с DXF+PLT, SVG-веер), джинсы (основа из каталога, 3D без внутренних деталей, паспорт образца). Любая ошибка на странице роняет тест. В CI гоняются на каждый push.

```bash
npx playwright install chromium   # один раз
npm run e2e                       # сборка + сценарии (~2 мин)
```
